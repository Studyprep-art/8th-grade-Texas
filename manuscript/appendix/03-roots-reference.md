# Greek & Latin Roots, Prefixes & Suffixes

Knowing word parts helps you unlock unfamiliar words on the test. *(Supports vocabulary standard 2C.)*

## Roots Named in the Grade 8 Standard
| Root | Meaning | Example |
|---|---|---|
| ast | star | astronomy, asteroid |
| qui | quiet, rest | tranquil, acquire |
| path | feeling | sympathy, empathy |
| mand / mend | order | command, recommend |
| duc | lead | conduct, educate |

## More Common Roots
| Root | Meaning | Example |
|---|---|---|
| port | carry | transport, portable |
| spect | look | inspect, spectator |
| dict | say | predict, dictate |
| scrib / script | write | describe, manuscript |
| tele | far | telephone, telescope |
| bio | life | biology, biography |
| graph | write, draw | paragraph, graphic |
| geo | earth | geography, geology |
| aud | hear | audience, audible |
| vis / vid | see | visible, video |

## Common Prefixes (word beginnings)
| Prefix | Meaning | Example |
|---|---|---|
| re- | again, back | rewrite, return |
| un- / in- | not | unfair, incorrect |
| pre- | before | preview, predict |
| mis- | wrongly | mistake, misread |
| dis- | opposite of | disagree, dislike |
| inter- | between | interact, international |
| sub- | under | submarine, subway |

## Common Suffixes (word endings)
| Suffix | Meaning | Example |
|---|---|---|
| -able / -ible | able to be | readable, visible |
| -tion / -sion | the act of | action, decision |
| -ology | the study of | biology, geology |
| -ist | one who | scientist, artist |
| -ful | full of | helpful, careful |
| -less | without | hopeless, careless |

> **Strategy:** When you meet a hard word, break it into parts. *Transport* = *trans* (across) + *port*
> (carry) → to carry across. Combine word-part clues with the **context** of the sentence (2B) for your
> best meaning.
