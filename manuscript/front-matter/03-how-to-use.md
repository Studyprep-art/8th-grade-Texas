# How to Use This Book

This book works for three kinds of readers. Find the path that fits you.

---

## Path A — The Student Studying on Your Own

1. **Start with "Getting Started."** Read how the test works, how it is scored, and how the online
   question types look on paper. This takes about 30 minutes and saves you from surprises.
2. **Pick a study calendar.** Use the 4-Week Sprint if the test is close, or the 8-Week Plan if you
   have more time.
3. **Learn, then practice.** For each subject, read the skill lessons and do the warm-up drills before
   you attempt a full test.
4. **Take one full test at a time, under test-like conditions** — quiet room, no phone, time yourself.
5. **Review every explanation,** including for questions you answered correctly. Understanding *why*
   an answer is right is how you improve.
6. **Fill in your diagnostic chart** after each test, then study your weakest strand next.

---

## Path B — The Parent or Tutor Helping a Student

- Use the **"A Guide for Parents and Teachers"** section at the back first. It shows you how to read
  the diagnostics and how to coach the written responses without giving away answers.
- Sit with the student for the **first** practice test to model pacing and the answer process, then
  let them work more independently.
- Focus praise on **effort and strategy**, not just the score. The score-tracking sheets make growth
  visible from test to test.

---

## Path C — The Classroom Teacher

- The lessons and drills map one-to-one to the **TEKS**, so you can assign them alongside your
  existing units. The **TEKS Coverage Index** at the back lists where every standard is taught and
  practiced.
- Each full-length test is blueprint-matched, so it works as a benchmark or a mock administration.
- Answer explanations include the TEKS code and a note on *why each wrong choice is wrong*, which
  makes them useful for reteaching and small-group work.

---

## The Symbols You Will See

| Symbol | Meaning |
|---|---|
| ★ | **Readiness standard** — tested heavily every year. Master these first. |
| ○ | **Supporting standard** — tested less often, but still fair game. |
| **Key Idea** | The one thing to remember from a lesson. |
| **Watch Out** | A common Grade 8 mistake to avoid. |
| **Try It** | A quick practice item to check yourself. |
| **Strategy** | A test-taking tip tied to the question in front of you. |

> **Tip:** Keep a pencil, scratch paper, and the Grade 8 Mathematics Reference Sheet nearby while you
> work. On the real test, these tools are available to you — practice using them now.
