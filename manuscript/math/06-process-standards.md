# Process Standards in Action (8.1 A–G)

The **mathematical process standards** are not a separate topic with their own questions — they are
*how* you do every problem on the test. STAAR builds them into questions across all four strands. Keep
them in mind as you work each lesson and practice test.

| Standard | What it asks you to do | How you use it |
|---|---|---|
| **8.1A** | Apply math to everyday life, society, and the workplace | Solve real-world word problems (cost, distance, savings) |
| **8.1B** | Use a problem-solving model | Analyze the given info, plan, solve, then check if the answer is reasonable |
| **8.1C** | Choose the right tools and techniques | Decide when to use the calculator, mental math, estimation, or the reference sheet |
| **8.1D** | Communicate ideas with multiple representations | Move between symbols, tables, graphs, and words for the same relationship |
| **8.1E** | Create and use representations | Draw a diagram, make a table, or sketch a graph to organize a problem |
| **8.1F** | Analyze relationships to connect ideas | See how slope, tables, and equations describe the same line |
| **8.1G** | Justify your reasoning with precise language | Explain *why* an answer is correct using correct math terms |

> **Key Idea:** Strong test-takers do more than "get the answer." They **check that it makes sense,**
> choose efficient tools, and can explain their thinking. Practice that habit on every item in this
> book.

> **Strategy:** After each answer, ask yourself: *Does this make sense?* A volume should be positive, a
> probability between 0 and 1, a slope matching the direction of the line. Catching an unreasonable
> answer is an easy way to save points.
